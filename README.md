# AuroraNimbus 
AuroraNimbus is an AI-powered embodied intelligence project exploring natural voice interaction, multimodal perception, spatial understanding, and expressive 3D avatars. 

## Vision 
To build an AI companion that can see, listen, understand its environment, communicate naturally, and interact through an expressive embodied interface. 
## Current Focus
- Real-time voice interaction
- Multimodal perception
- 3D spatial understanding
- Expressive 3D avatar
- Persona and long-term interaction
- Low-latency AI pipeline 
## Status 
Work in progress.
